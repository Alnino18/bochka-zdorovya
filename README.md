# 🌿 Бочка Здоровья (Bochka Zdorovya) — PWA & Salon Accounting

За современное спа-пространство и оздоровительный комплекс **«Бочка Здоровья»** (Фитобочка, Сауна, Массаж).
Компактное, адаптивное и интуитивное прогрессивное веб-приложение (**PWA**) для ежедневного учёта мастеров, клиентов, выручки, бара, расходов и быстрого доступа к прейскуранту.

---

## 📱 Основные возможности (Features)

1. **Двуязычный интерфейс (O'zbekcha / Русский)**:
   - Мгновенное переключение языка без перезагрузки страницы (`UZ` / `RU`).
2. **Прейскурант и каталог услуг**:
   - Полный перечень всех 8 категорий процедур и 10 вариантов цен (40 мин / 60 мин в сумах).
   - Быстрый поиск и фильтрация по длительности.
   - Быстрые кнопки связи: звонок по телефону (`+998 97 002-04-04`) и переход в Instagram (`@Bochka_zdorovya`).
3. **Интерактивный журнал ежедневного учёта**:
   - Учёт работы мастеров (Иро, Мах, Комила и др.) с подсчётом принятых клиентов и выручки.
   - Автоматический расчёт доли мастера и чистой кассы салона.
   - Учёт дополнительных доходов (Бар) и расходов заведения (Уборка).
   - Реестр записей и бронирования клиентов (телефон, имя, время, заметки).
   - Предустановленные базовые данные за **19 и 20 ноября** из рабочего блокнота.
   - Надежное сохранение данных в браузере (`localStorage`) с функциями экспорта/импорта резервных копий (JSON Backup).
4. **PWA (Progressive Web App)**:
   - Установка приложения на домашний экран смартфона или ПК в один клик.
   - Офлайн-режим благодаря Service Worker и кэшированию ресурсов.
   - Современные векторные и маскируемые иконки высокого разрешения.

## 🛠 Технологический стек

- **Frontend**: React 18, TypeScript, Vite
- **Стилизация**: Tailwind CSS, Lucide React Icons
- **PWA**: Service Worker Cache API, Web App Manifest
- **Тестирование**: Vitest (22 тестовых файла, 172 автоматических теста — 100% pass)
- **Деплой**: Готовые конфигурации для **Render** (`render.yaml`) и **Firebase Hosting / Firestore** (`firebase.json`, `firestore.rules`)

## 🚀 Запуск и разработка

### Установка зависимостей:
```bash
npm install
```

### Запуск локального сервера разработки:
```bash
npm run dev
# Откройте в браузере: http://localhost:5173
```

### Сборка production-версии:
```bash
npm run build
```

### Запуск тестов:
```bash
npm test
```

## ☁️ Развертывание (Deployment)

### 1. Render (render.yaml)
В корне репозитория настроен файл `render.yaml`.
1. Подключите репозиторий `Alnino18/bochka-zdorovya` в [Render Dashboard](https://dashboard.render.com).
2. Выберите тип **Static Site** (или примените Blueprint из `render.yaml`).
3. Настройки сборки установятся автоматически:
   - Build Command: `npm install && npm run build`
   - Publish Directory: `./dist`

### 2. Firebase & Firestore
Проект готов к публикации через Firebase CLI:
```bash
firebase deploy --only hosting,firestore
```
